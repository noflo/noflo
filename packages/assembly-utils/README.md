# @noflo/assembly-utils

Utility components for [NoFlo](https://noflojs.org) Assembly programs
(the message-relay convention provided by [`@noflo/assembly`](../assembly)).

## Components

- **ToAssembly** — convert regular NoFlo data to an assembly message
  (`{ errors: [], data }`)
- **FromAssembly** — convert an assembly message back to a regular packet;
  the first accumulated error goes to the `error` port
- **Fork** — fork an assembly message to all connected connections
- **Merge** — merge assembly messages from all connections
- **All** — collect streamed assemblies from all connected inputs into one
  message
- **ComparePath** — compare a JSONPath-extracted object value and route to
  `pass`/`fail`

These components are also the building blocks of the adapter graphs
generated by `asAssembly` (work document #36).
